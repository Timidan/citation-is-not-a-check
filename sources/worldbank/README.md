# World Bank population source packets

Thirty 2023 items use six population-share series published in World Development Indicators. The six are ages 0–14, ages 15–64, ages 65 and older, urban, rural and female. WDI indicator metadata attributes the age series to UN Population Division's World Population Prospects, the urban/rural series to World Urbanization Prospects with national definitions, and some female and rural estimates to World Bank staff using UN sources. Age groups are related and rural and urban shares are complementary. Treat indicator codes as document clusters within these shared source products. [Official Indicators API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api)

Each item compares two countries from the same WDI regional group, series and year. The official WDI country listing excludes aggregate regions from eligibility. Both values appear in the same saved API response and in the four-row excerpt. Excerpts preserve source response order and the API's exact decimal values. Each table contains original country and indicator labels, the observation year, the percentage values and the indicator's publisher credit. The `snapshot_file` path is relative to this directory.

Five items were selected per series. The deterministic selector used seed `20261113`, required a difference of 0.25–5 percentage points, used each target/distractor country code once within the family, and assigned magnitude and table position before selecting eligible country pairs. The resulting cohort has 15 larger and 15 smaller targets, 15 targets above and 15 below their distractor, and 8/7/7/8 targets in the four table positions. Prior demographic knowledge can still help answer some questions. No subject outcomes informed selection.

`manifest.json` records the saved byte digests, official URLs and UTC retrieval timestamps; `selection-audit.json` records the item assignments. Independent machine verification checked every displayed row and key against the raw snapshots. Independent human review is pending.
