# EIA source cohort

Thirty state-specific 2024 State Electricity Profile pages, each used once. The source passage preserves the complete, adjacent **Net summer capacity (megawatts)** and **Net generation (megawatthours)** sections of Table 1, including the original Item, Value, and Rank columns and the table's data-source footer. The question always selects the Value column in the generation section. The two candidate values are the Electric utilities and IPP & CHP rows in that section. The table caption identifies the state and 2024 vintage even where the page's title metadata has a stale year. [EIA profile index](https://www.eia.gov/electricity/State/index.php) · [Alabama profile example](https://www.eia.gov/electricity/state/alabama/index.php)

The fixed row pair was checked in all 50 states. Electric utilities had the larger value in 33 states and IPP & CHP in 17, with zero ties. The selection took the first 16 and first 14 states in ascending state FIPS order within those two strata, respectively. Within each stratum, the target alternates Electric utilities and IPP & CHP, starting with Electric utilities. This yields 15 targets in each earlier/later position and 15 larger/15 smaller targets. This is a source-based convenience cohort. The 30 state documents share an EIA publication, data collection and template. No subject outputs were used for source selection. [Selection audit](selection-audit.json)

The [manifest](source-snapshots/manifest.json) records the retrieval URL, final URL, UTC timestamp, and SHA-256 for each unmodified HTML response. Paths in items.json resolve from this directory. Any later update to the live profile does not alter the frozen values.
