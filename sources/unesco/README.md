# UNESCO UIS education source packets

Thirty 2023 education items use six modelled completion-rate series from UNESCO DataHub's official UIS SDG 4 dataset `uis001`. The series cover primary, lower secondary and upper secondary education, each with both-sex and female observations. Row footnotes credit the GEM Report completion estimates dated 5 February 2026. The six series use the same estimation product and are related. Indicator codes serve as document cluster IDs; the six clusters do not establish six independent producers. [Official dataset](https://data.unesco.org/explore/assets/uis001/)

Each item compares two countries from the same UNESCO regional group and the same series and year. Both values appear in the same saved API response and in the four-row excerpt. Excerpts retain the provider's order within the query's country-code sort and reproduce the exact numeric value, including decimals inherited from the API's numeric representation. Only unqualified rows with a single matching source footnote were selected. Nearby eligible rows provide context, with the excerpt identifying that it shows selected rows. The `snapshot_file` path is relative to this directory.

Five items were selected per series. The deterministic selector used the fixed seed `20261113`, required a difference of 0.25–5 percentage points, used each target/distractor country code once within the family, and assigned magnitude and table position before selecting eligible country pairs. The resulting cohort has 15 larger and 15 smaller targets, 15 targets above and 15 below their distractor, and 8/7/7/8 targets in the four table positions. Country, regional and modelled-series knowledge may still offer shortcuts. No subject outcomes informed selection.

The official modelled out-of-school series were considered alongside completion. Those queries returned records on an initial discovery request and empty arrays during the later acquisition. The latter responses are retained for provenance. The finished education cohort uses completion only. `manifest.json` records the saved byte digests, official URLs and UTC retrieval timestamps; `selection-audit.json` records the item assignments. Independent machine verification checked every displayed row and key against the raw snapshots. Independent human review is pending.
